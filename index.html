TMDB API Configuration

CineMatch uses a secure Node.js backend proxy. Your TMDB API key is kept safely in .env on the server and is never exposed to the browser.

1 Get a free API key at themoviedb.org (Settings → API)
2 Open the .env file in your project root
3 Add your key: TMDB_API_KEY=your_key_here and restart server

How CineMatch Recommends Movies

Transparent Content-Based Filtering & Weighted Feature Matching

Algorithm Principles

Unlike opaque deep learning models, CineMatch uses a deterministic content-based filtering model that scores movies based on their metadata features extracted from TMDB.

Mathematical Scoring Formula
Score(M) = Σ (W_pref × Match_pref) + Σ (W_like × Match_like) + (Rating × 0.2) + min(2.0, log10(Pop + 1))
Factor Weight Description
Explicit Genre Match +4.0 pts Awarded for each genre matching user's selected preferences.
Liked Movie Association +3.0 pts Weighted by frequency of genres found in movies you liked.
Quality Rating (TMDB) Up to +2.0 pts Calculated as (vote_average / 10) × 2.0.
Popularity Factor Up to +2.0 pts Logarithmic scale log10(popularity + 1) to prevent bias.
Disliked Exclusions Filtered Out Disliked movies and already-liked titles are excluded.

Worked Example:

If your preferred genres include Sci-Fi and Action, and you liked Inception:

  • A movie like Interstellar (Sci-Fi, Drama | Rating: 8.4) receives:
    • Explicit genre match (Sci-Fi): +4.0
    • Liked movies history match (Sci-Fi): +3.0
    • Rating quality: 8.4 × 0.2 = +1.68
    • Popularity factor: +1.32
    → Total Score: 10.0 / 10.0 → 98% Match Badge
